## 三、本轮新发现缺陷（已修复）

**PET-V07-001 · 预览页 iframe 内 script 结束标签被双重转义，视线跟随交互静默失效**

| 字段 | 内容 |
| --- | --- |
| 复现步骤 | 运行 `build_pet_preview.py` 生成 `pet-v07-preview.html` → 浏览器打开 → 鼠标移到 **iframe 内**角色区域 → 读取 `#stage` 的 `--gaze-x`；或跑 `pet_v07_browser_smoke.py` |
| 预期结果 | iframe 内 `pointermove` 监听写入 `--gaze-x/y/near`，头部 3D 转向、眼神高光位移、贴头时光晕点亮 |
| 实际结果 | **已确认**：`build_pet_preview.py` 原第 243 行为 `+ '<\\/script></body></html>';`，node 探针求值后写入 srcdoc 的是 `<\/script>`（`含合法结束标签 </script>: false`）；HTML 解析器不认该结束标签 → iframe 内 `<script>` 未闭合、整段 JS 不执行 → `--gaze-x` 始终为空。冒烟证据：`gaze-x  → 0.524`（首次空、第二次落在 iframe 外由父页映射才有值），汇总 6/7 |
| 导致的现象 | 预览页「鼠标移到小su 身上会转头」全程失效；只有鼠标在 iframe 外桌面空白区才生效，人工验收会误判成「视线跟随没做」。影响范围：**预览页与依赖它的自动化验收**；产品 `overlay.tsx` 不受影响（Tauri 悬浮窗为单文档，无 iframe） |
| 根因 | 父页内联脚本不能出现字面 script 结束标签，需转义；但误用了两个反斜杠，JS 字符串求值后仍保留反斜杠，srcdoc 拿到非法标签 |
| 修复后的结果 | 改为单反斜杠 `'<\/script>'`，srcdoc 得合法 `</script>`（探针 `true`）。冒烟 7/7，视线 `gaze-x -0.829 → 0.237`、贴头 `near 0.999 / nearby=true`。验收：`build_pet_preview.py` 内置 `validate_frame_script()`、`check_pet_overlay.py` 新增 D07、浏览器冒烟视线断言 |
| 问题类型 / 定位 | 前端 UI / 测试工具　·　`docs/孙测测/scripts/build_pet_preview.py:243` |
| 优先级 / 严重级别 | P1 / Major（验收链路失真，非产品运行时故障） |
| 状态 | **已修复** |

**排除项（怀疑过但核实不成立）**：
- 产品 `overlay.tsx` 的 `document.pointermove` 监听失效 → 不成立：运行时无 iframe，契约 C15 命中 `--gaze-x` 等字段；冒烟失败只发生在 iframe 内移动。
- 纯属冒烟脚本时序问题（首次 `mouse.move` 只触发 `pointerenter`）→ 不成立：node 探针独立证明 srcdoc 标签非法，即使加预热、脚本不闭合仍不会写入；预热仅用于消除残余抖动。
- 动画 WebP 在 iframe 内不播放 → 不成立：独立 `anim-only.html` 整页采样 7 次得 6 个不同帧，与脚本闭合无关。
- 父页 `desktop` 映射缺失 → 不成立：第二次移动落桌面区时有值 `0.524`，父页链路本就正常。

## 五、遗留风险与待验证推断（不作已确认结论）

1. **原生窗口组合未双平台实测**：Windows WebView2 / macOS WKWebView 下「原生拖动 + 鼠标穿透 + 带 alpha 动画 WebP 解码」的组合表现未验证；浏览器冒烟用的是 Chrome headless。需真机核对动画 WebP 是否逐帧播放、拖动后 `click` 是否误触。
2. **窗口级矩形穿透（点击）**：互动模式解除 `set_ignore_cursor_events` 后，OS 仍按整个窗口矩形拦截点击（含左侧透明通知栏）；CSS 只缩小 React 热区。**视线/靠近倾听已不依赖解除穿透**：2026-11-09 起 overlay 轮询 `pet_global_cursor`（OS 全局物理坐标）驱动 gaze/peek/walk。
3. **流式守卫极端路径**：客户端挂起且不断开时 `active_requests` 保持在途；单测覆盖 drop 释放，长连接异常未做压力验证。
4. **包体积上升**：85.45 KB → 404.23 KB（+318.78 KB）。zip 对已压缩 WebP 二次压缩收益极小，需打版时确认安装包实测增量。
5. **许可证待核实**：Qwen-Image / Qwen-Image-Edit fp8 权重与 Lightning LoRA 的模型卡许可证是否允许随 Apache-2.0 仓库分发；宣传物料发布前逐项确认。
