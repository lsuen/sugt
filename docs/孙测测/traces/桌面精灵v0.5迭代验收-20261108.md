## 五、修复后结果汇总

- 精灵默认出现在**主屏右下角**，尺寸 120×160，可在设置里切小/中/大三档或一键回右下角。
- 移动交互从「进编辑态 → 拖 → 点保存」简化为**直接拖、松手自动贴边吸附并持久化**；单击/拖拽互斥避免误触。
- 素材变为**完整全身**（含腿、袜、鞋），四手 bug 根除，发丝缝隙抠净，五帧构图统一，状态切换不再忽大忽小。
- 包内素材从 110.72 KB 降到 **85.45 KB**。

## 六、遗留风险与放行结论

| 编号 | 风险 | 级别 | 说明 |
| --- | --- | --- | --- |
| R1 | 双平台拖动与鼠标穿透未实机验证 | P1 / 待验证推断 | 本轮改动了 `start_dragging` + `onMoved` + `set_ignore_cursor_events` 组合，Windows WebView2（尤其 150% 缩放）与 macOS WKWebView 行为可能不一致。**发版前必须双平台真机验证拖动、贴边吸附与穿透恢复** |
| R2 | 窗口级穿透无法做到像素级 | P2 / 已确认 | Tauri `set_ignore_cursor_events(false)` 会让整个 120×160 窗口矩形吞掉鼠标事件，CSS 热区只能减少前端误触，不能把事件透传给下层应用。窗口已缩小以缓解；彻底方案需后端按全局鼠标位置动态切换穿透 |
| R3 | sleep 帧仍为睁眼 | P3 / 已确认 | Qwen-Edit 2509 两轮重出均未执行闭眼（角色一致性约束过强），v1 的橙色实心圆已消除。休息态靠降饱和 + 慢呼吸 + 灰状态灯区分；如需真闭眼应改用局部重绘 inpaint |
| R4 | Qwen 系权重许可证 | P2 / 待验证推断 | fp8 权重与 Lightning LoRA 的模型卡许可证是否允许随 Apache-2.0 仓库分发仍未核实，宣传物料发布前逐项确认 |

**放行结论**：功能在开发环境可通过验收，14/14 用例通过、全量套件全绿；**R1 未闭环前不建议发版**。R2/R3/R4 为已知留白，不阻断内部试用。
