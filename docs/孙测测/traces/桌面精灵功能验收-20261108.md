## 四、缺陷分布与已知瑕疵

- 功能缺陷：**0**（P0 0 / P1 0 / P2 0 / P3 0）。
- 素材层已知瑕疵 2 项（不阻断功能，已写入 `src/assets/pet/ASSETS.md`）：
  1. `su-sleep.webp` 闭眼被图生图渲染成橙色实心圆，配降饱和与慢呼吸后接近打盹，但非标准闭眼线稿。
  2. `su-error.webp` 与 `su-idle.webp` 表情差异偏小，异常态主要靠红核心 + 摇晃动效 + error 气泡区分。
  - 处置：后续用 Qwen-Edit 单独重出替换即可，不影响代码。

## 五、排除项（核实后不成立）

- **不是云端额度消耗**：本轮 5 帧全部由本地 ComfyUI 生成，`/history` 有对应 prompt_id，未调用内置 ImageGen。
- **不是「透明视频跨平台解码」风险**：进包载体是 WebP 序列帧（图片），视频未进包。
- **不是主题 token 缺失**：`overlay.html` 是独立 vite 入口，本就不加载 `registry.ts`；精灵颜色集中在 `overlay.css` 的 `--pet-*` 局部变量，未违反组件硬编码品牌色规范。
- **不是新增窗口 / 新增权限面**：复用既有 `overlay` 窗口 label 与 `allow-overlay-commands` permission，仅追加一条只读命令。
