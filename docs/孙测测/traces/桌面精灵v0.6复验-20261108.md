## 四、遗留风险与待验证推断（不作已确认结论）

1. **原生拖动事件派发**：Windows WebView2 / macOS WKWebView 下 `start_dragging()` 从 `mousemove` 触发后的 `pointerup` / `click` 派发差异未双平台实测；已用 5s 超时 + `blur` 兜底，但需真机验证「单击回主窗口」与「拖动后不误触」。
2. **窗口级矩形穿透**：互动模式解除 `set_ignore_cursor_events` 后，操作系统层仍按整个窗口矩形拦截点击（含左侧透明通知栏）；CSS 只能缩小 React 热区，像素级穿透需原生全局鼠标钩子，属已知架构限制。
3. **`su-sleep.webp` 仍近似睁眼**：靠降饱和、慢呼吸、灰色状态灯区分，真机观感待确认；如需真闭眼需重出素材。
4. **流式守卫的极端路径**：客户端挂起且不断开时 `active_requests` 会保持在途；hyper 在连接关闭时丢弃 body 会释放守卫（单测已覆盖 drop 路径），但长连接异常未做压力验证。
