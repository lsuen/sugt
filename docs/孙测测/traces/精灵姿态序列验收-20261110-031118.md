- 本门禁只验收「同一 master 派生的姿态序列」是否可批量生产；
  通过不等于素材已落包，落包还需 SCR-017 + manifest v2 + 全套替换。
- 脚部底边距过小是生产前置风险：送 Edit 前必须给输入图底部留白，
  否则任何构图漂移都会裁掉鞋子。
- 背景色逐张漂移是常态，色键必须按本图背景 score 自适应，
  禁止写死单一背景色。
