## 10. 追加：动作时长对齐（2026-11-11 14:15，用户反馈「动画没播完就切」）

- 期望每个动作都至少完整播完一遍再切回基态，因为用户能直接看出「播到一半被硬切」，用 `npm run test:pet-state` 的三条时长断言 + C37b/C46b/C38 门禁验证。
- 根因：`playIdlePose(pose, ms)` 的 `ms` 是视觉停留（到点 `setIdlePose(null)`），与素材真实时长无关。`manifest.autoActions` 写死 2200 / 1600 / 3500 / 3000 / 420，全部短于素材。
