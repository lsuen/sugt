# 小su 素材生产经验（ComfyUI 本地链路）

只在重新生成素材时需要读。日常改代码、改几何参数不需要 ComfyUI。现行数字（动作数、帧数、画布、体积）以 `src/assets/pet/manifest.json` 与 `config/normalize-baseline.json` 为准，本文不重复。

## 生产链

`traces/assets/su-cel-good-fixed.png`（定稿母版）→ `comfyui_pet_action_series.py`：Qwen-Image-Edit 2509 + Lightning-4steps + Multiple-angles LoRA 出关键姿势 → MiniMax H3 FL2VA 补间 → 逐帧自适应色键（缓存到 `cutouts/`）→ 归一化 → `pet_reencode_assets.py`（56 色 palette-lossless）→ `gen_pet_from_manifest.py` → 门禁。断点续跑靠 `state.json`（`--phase keys|interpolate|frames|encode`）。新增动作的唯一落包流程见 `README.md` 流程 B。

- 原始 H3 视频（`SUGT_PET_WORK/videos/*.webp`）是唯一图像源。尺寸、边距、画布、hitBox 调整只重跑离线的 `--phase frames`，不重新调 ComfyUI；只有源视频里缺像素（手指、发梢、鞋底被生成画布截断）才重新生成。
- 生成画布 `640×768`，`SUGT_PET_MASTER_SCALE` 默认 `0.78`。512 宽会永久截掉指尖和发梢，离线归一化补不回来。`edge_touch_score` 是生产门禁，最多换 3 个种子，仍失败记入 `state.json.rejected`。
- 归一化只做纯缩放和平移，不裁人物像素：每个动作取 50 帧 `tight_box` 的并集，全局求一个目标身高，所有动作共享脚线和水平中心。`do_frames()` 自检四边留白 ≥6px、跨动作身高极差 ≤8%、并集外实心像素 ≤2%。脚下留白在归一化时加，不能指望源视频。
- 眨眼额外帧不能与睡觉海报同字节，否则打包器按内容哈希去重，dist 少一张（门禁 D04）。
- ComfyUI 脚本发请求前先调 `comfyui_curl_http.install()`：Python socket 到局域网 ComfyUI 主机会报 `Errno 65`，curl 正常。试跑输出只写临时目录。

## 提示词规律（Qwen-Image fp8 + Lightning 实测）

- 母版提示词要短，硬约束放最前；约 900 字的长中文提示词会丢掉尾部指令。
- 「全身」要点名下半身：裤子、两条完整小腿、两只鞋、腿间空隙，并附英文 `full body head to toe, both legs fully drawn, both shoes visible, no cropping`。
- 不要正向描述头顶任何东西（头顶、光环、发饰），否则必出发光光环；负面词写 `halo` 压不住。
- 白底与全身两块硬约束用英文并排放最前，只放一块会挤掉另一块。
- 文生图只用于一张母版；所有表情和动作从锁定母版图生图派生。
- 抬起类动作会让模型把人物倒挂。正向写 `STILL UPRIGHT / head at top / feet at bottom`，负向写 `upside down, inverted, hanging by the feet`；管线用「白鞋质心 − 皮肤质心 > 0.08」判断朝向，倒置就换种子重来。
- 要求「脚下留大块空白」会画出发光青色平台。正向写明脚下与背景是同一纯色，负向加 `bright cyan ellipse / glowing platform / podium / spotlight circle / ground disc / light pool / turquoise circle / stage`。

## 抠图规律

- 底色用饱和纯色（青蓝 `RGB(91,145,190)` 一类），不用白底或品红：白底会和白 T 恤、白袜、白鞋冲突。
- 用全局 `chroma` 模式，不用连通域漫水填充：大片发丝会围出漫水够不到的背景孤岛。
- Edit 2509 与 H3 都会让底色漂移，阈值按每帧四角实测的背景分数缩放，不写死一个颜色。
- 四角均匀不代表能抠干净。新母版先过 `check_pet_keyvisual_cutout.py`（五项检查），外部交来的抠图先过 `check_pet_cutout_asset.py --fix`（清色边溢出、清 alpha=0 下的 RGB 垃圾、体积预算）。
- 生产输入过 `check_pet_pose_series.py`（脚下留白、平台、朝向），落包 1250 帧过 `check_pet_final_frames.py`。两层都要绿。
