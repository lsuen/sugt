# 精灵素材清单（v1.3.3 定版快照）

> 生成日期：2026-11-10　|　数据来源：`src/assets/pet/`　|　唯一进包路径：`src/assets/pet/`
> 本文件是**清单**，不是素材副本：避免同一份 WebP 在仓库里出现两份真相源。
> 需要完整快照时执行 `python3 scripts/petctl.py snapshot`，会把 41 张复制到本目录 `assets/final/`。
> v1.3.3 仅 `wake` 一段由本地 ComfyUI 用 `640×768` 画布重新生成（修复源画布裁掉手掌）；其余 19 段仍是 v1.3.2 的 `512×768` 视频。因 20 动作共用同一 `h_ref`，换一段仍需**全量**离线归一化，故 41 张体积与哈希全部按本轮落包实测刷新。
> 体积与哈希按 `src/assets/pet/` 当前 41 张 WebP 实测填写；`wake` 修复前快照见 `ASSETS.md §11.3`。

## 规格

| 项 | 值 |
| --- | --- |
| 素材画布 | `180×297` @2x（`manifest.baseSize`） |
| 动作数 × 每动作帧数 | 20 × 50 = **1000 张独立位图** |
| 编码 | 56 色 palette-lossless WebP / `dither=none` / `method=4` |
| 帧序 | `frameOrder` 为 `0..49` 无重复排列，禁止重复帧冒充扩容 |
| 逐帧时长 | 见 `manifest.json` 各动作 `frameMs` |
| 附加帧 | `su-blink.webp`（sleep 序列第 25 帧，必须与 sleep poster 字节不同） |
| 人物尺寸 | 全局目标身高 `h_ref = 176.0px`；20 动作高度极差 1.1%（v1.3.2 为 186.6px / 1.6%，全部等比缩小约 5.7%） |
| 安全边 | 最小四边留白 13px；并集框外实体像素 0.000%（不裁肢体） |

整包：**41 张 / 4713188 B = 4.713 MB / 4.49 MiB**（预算 5–8 MB）
