## 0. 一句话目标

把进包画布从 `180×297` 扩到 `240×297`（左右各 +30px **全透明**），让以后的新动作伸展不会再被画布裁掉；同时补 4 个闲置动作、修 `stretch` 双臂被裁、消息框去阴影扁平化；要求人物屏幕像素高不变、点击体感不变、包体积基本不变。

## 1. 已拍板决策（**不得再回头问用户**）

| 项 | 决定 | 依据 / 理由 |
|---|---|---|
| 画布 | `240×297`，左右各补 30px 全透明 | 够放伸懒腰 / kickflip 的伸展；270 要多加宽约 50%，边际收益小 |
| 缩放方案 | **方案 A**：窗口三档宽度按 `240/180 = 4/3` 加宽，height 不变；`--pet-side-w: 28%` **不动** | A 只改 `PET_SIZES` + 一条断言，CSS 布局一处不动；方案 B（压侧栏到 10%）会把气泡 `max-width` 从 ~93px 挤到 ~67px、状态胶囊位移，回归面大，已否决 |
| 不变式 | `盒子宽 / 画布宽 ≥ 盒子高 / 画布高`（高度主导） | 满足则 `factor = 盒子高/297`，与画布宽无关 → 人物像素级不变。写进 `check_pet_overlay.py` 作硬断言 |
| 归一化 | **不重算 `h_ref`（176.0）、不重新抠图、不缩放人物、不用 `frame.crop()`** | 41 张素材逐帧纯 paste 补边，人物 alpha 1:1 不变 |
| 新动作归一化 | **锁定 `h_ref=176.04` / `foot_y=237`，画布直接 `240×297`、水平中心 `120`** | 生产线 `do_frames()` 对单动作会重算 `h_ref`（`comfyui_pet_action_series.py:778`），新动作必然与老 20 动作不同高，且单动作 `spread=0` 自检发现不了。桥接脚本复刻同式但锁基准，见 §9 |
| 全量重生成 | **不做** 19 段 512 视频的全量重生成 | 用户明确「先不全量跑了，我现在用着也还能接受」 |
| `cropBox` | 重定义为整幅 `[0,0,240,297]` | `gen_pet_from_manifest.py:70` / `pet_reencode_assets.py:61` 硬校验 `cropBox 宽 == baseSize.w` |
| 动作 / 帧 / 张数 | **24 动作 × 50 帧 = 1200 帧；49 张**（24 poster + 24 loop + `su-blink`） | 4 个新动作各 50 帧 |
| 新动作键名 | `squatDraw`（蹲着画圈圈）、`wiggleDance`（扭扭舞）、`kickflip`（滑板）、`miniGame`（玩小游戏），全部 `playback: loop` | loop 只需 start 关键帧，不进 `_END_PROMPTS`；闲置动作循环更自然 |
| `stretch` | 用 `640×768` 重生成一版修双臂被源画布裁掉 | 用户点名「可以修那个伸懒腰的素材用新的就行」 |
| 消息框 | 删 `.pet-bubble:141-144` / `.pet-menu:599` 的 `box-shadow`、删气泡/菜单的 `backdrop-filter`，扁平纯色 + 主题 token | 用户「不要带阴影」；硬零背景红线仍允许控件自身面板色 |
| ComfyUI | 本地 `http://192.168.31.84:8188`（**curl 必须 `--noproxy '*'`，否则办公代理返回 502 假阴性**），每个动作 3 个 seed 版本，**串行** | `upload_image` 固定文件名 + `overwrite=true`，并行会互相覆盖 |
| 提交 | 最终 **不自动 commit**，列清单等用户确认 | 用户长期规则 |

## 2. 红线（违反即回滚）

1. **禁止拉伸/裁切人物**：补边是往透明画布 paste，不是缩放；任何 `frame.crop()`、`resize` 人物、重算 `h_ref` 都禁止。
2. **单层素材**：每个 `.pet-loop[data-loop]` / `.pet-poster[data-frame]` 只挂一张 WebP；CSS 多值 `background-image` 是叠加不是 fallback（契约 C17）。
3. **硬零背景**：`overlay.html` 与 `.pet-stage` 保持 `background: transparent !important`；`overflow: hidden` 不改；禁止 `.pet-halo` / `.pet-ground` / 舞台底板 / 地面影 / `filter: drop-shadow`。预览页棋盘格只在虚线窗外。
4. **命中区**：`PET_IMAGE_SIZE` 改 240×297 后，**24 个动作的 `hitBox` 必须按新画布全量回填**（`gen_pet_from_manifest.py` 写模式自动做）。漏改 → 点击框偏位或透明边变点击墙。
5. **请求态不被抢**：新闲置动作只在 `state === 'idle'` 触发，不覆盖 typing / error / done / 请求在途。
6. **生成块禁止手改**：`pet.css` 的 `@generated:pet-assets` 与 `petManifest.generated.ts` 一律跑生成器。
7. **改 `pet.css` 必重跑 `build_pet_preview.py`**：D05 比对源 CSS sha256，任何字节改动不重跑必红。
8. **两份脚本副本同步**：`docs/孙测测/scripts/` 改完必须 `petctl.py sync` 到 `docs/小精灵维护/scripts/`；`config/manifest.json` 快照要 `cp` 同步，否则 `doctor` 判红。
9. **保留用户文件**：工作区 4 个未跟踪的 `docs/孙测测/traces/剪裁一致性检查-20261110-*.md` 属用户/其它会话产物，不删不改。
10. **历史留痕只增不改**：`docs/孙测测/traces/*.md` 历史结论永久保留，不回填改数字。

## 4. ComfyUI 任务规约

- 服务：`http://192.168.31.84:8188`（ComfyUI 0.36.0，Windows，无认证）。**办公代理会返回 502 假阴性**，脚本已用 `curl --noproxy '*'` 适配；手工探测必须加 `--noproxy '*'`。
- 解释器：**`/usr/local/bin/python3.13`**（唯一装 Pillow 11.2.1 的）；PATH 上的 `python3` 无 PIL，不可用。不依赖 `requests`。
- 环境变量：`SUGT_COMFYUI_BASE`、`SUGT_PET_CANVAS=640x768`、`SUGT_PET_H3_STEPS=8`、`SUGT_PET_EDIT_STEPS=4`、`SUGT_PET_MASTER_SCALE=0.78`、`SUGT_PET_WORK`（每版独立目录）。
- **前置依赖（顺序不可颠倒）**：脚本 `parse_args` 从 `manifest.json` 的 `poses[]` 校验 `--action`（`1015-1020`），`do_keys()` 从 `_POSE_PROMPTS` 查表（缺键 `RuntimeError`）。所以「先发任务」前必须先做**最小前置登记**：manifest 追加 4 条 poses + `_POSE_PROMPTS` 追加 4 键 + 同步脚本副本。此阶段只加动作、**不动画布**。
- **中间态红灯是预期**：前置登记后 manifest 有 24 动作但素材仍 41 张、帧预算仍 1000，门禁会红；主线 §3 全部改完即恢复全绿。接手者不要误判为回归缺陷。
- 多版本：脚本原生**没有** `--seed/--variants`，seed 由 `20261200 + index*17`（keys）与 `20261300 + index*23`（interpolate）派生。**已落地改进**：新增 `SUGT_PET_SEED_OFFSET`（脚本 `:79` 常量、`:430` keys、`:469` interpolate），默认 0 不改变旧行为；每版一个独立 `SUGT_PET_WORK` + 不同 offset（0/1000/2000），只跑目标动作，无陪跑浪费。前置登记脚本：`/tmp/sugt-pet-v14-prepare.py`（幂等），备份：`/tmp/sugt-pet-v14-backup-pre/`。
- **必须串行**：`upload_image()` 用固定文件名 + `overwrite=true`，并行提交会互相覆盖服务端 input。禁止 `--force`。
- 只跑 `--phase prepare → keys → interpolate`；**不跑 `encode`**（`encode` 会改写仓库 `manifest.json` 与 `src/assets/pet/*.webp`）。`frames` 离线，挑版后再跑。
- 门禁：`edge_touch_score` 四边触边 `sides == 0`；`guarded_edit` 朝向 + 触边；三次不过 `rejected` 留痕。
- **产物路径**：`/tmp/sugt-pet-v14-<action>-v<N>/`（state.json / videos / keys / master）；批次日志 `/tmp/sugt-pet-v14-batch.log`；批次脚本 `/tmp/sugt-pet-v14-batch.sh`。v13 旧目录 `/tmp/sugt-pet-actions-v13/` **只读不写**。
- **不盯**：提交后台后立刻转主线，不轮询、不等待；等系统通知。若主线完成而 ComfyUI 未完，先回归「老动作影响」，等结果回来再补「新动作嵌入」回归。
- `staged.json` 属技能商店元数据，与本任务无关；不要找它。

## 9. 落包桥接（阶段 C 唯一执行手册）

### 9.1 为什么必须补桥接脚本

只读调研（2026-11-11）确认：**仓库里没有「单动作 `640×768` → `240×297`、纯缩放+平移、不裁人物、且锁定老动作身高」的现成脚本**。

- `comfyui_pet_action_series.py:687-908 do_frames()` 是全量归一化：`:703` 只认 `state["videos"]`、`:778` **动态重算** `h_ref = min(bounds)`、`:891` 的跨动作高度极差自检在单动作时 `spread=0` **发现不了身高漂移**。对单候选目录跑 `--phase frames` 会让新动作与老 20 动作不同高。
- `comfyui_pet_action_series.py:911-939 do_encode()` 会按完整 24 poses 整套覆盖 `src/assets/pet/*.webp` 并改写 `manifest.cropBox/cropNote`；单目录 source 只有 1 个动作会直接 `FileNotFoundError`。**禁止在挑版阶段跑**。
- `pet_v14_pad_canvas.py` 只做 `180×297 → 240×297` 纯 paste，输入必须是已归一化的动画 WebP，不处理 `640×768` 源视频。
- `pet_reencode_assets.py` **不做归一化**，只按 `cropBox`（现为整幅）crop + 56 色编码；`h_ref` 不在该脚本。

### 9.2 解法：锁定基准，只换画布宽度

v1.3.3 基准来自 `/tmp/sugt-pet-actions-v13/state.json` 的 `normalise`：`canvas=[180,297]` / `h_ref=176.04` / `foot_y=237` / `safe=[11,18]`。桥接脚本 `docs/孙测测/scripts/pet_v14_finalize_assets.py` 复刻 `do_frames()` 的并集安全框 + 纯缩放平移，但：

```text
scale  = 176.04 / (代表帧 alpha bbox 高度)      # 与生产线 :782 同式，不重算
offset = (120 - 代表框中心 x * scale, 237 - 代表框底 y * scale)
画布   = 240×297                                # 水平中心 90 → 120（= 老动作补边 +30 后位置）
```

→ 新动作人物代表高度恒为 176px、脚底 y=237、水平中心 120，与老 20 动作**像素级对齐**；左右可用空间从 90px 增到 120px，正好容纳 `stretch` 双臂与 `kickflip` 滑板。归一化全程 `Image.LANCZOS` 缩放 + `paste(resized, offset, resized)`，**不裁一像素人物**，并集框外只清色键噪点。
