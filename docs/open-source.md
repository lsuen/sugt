# SUGT 开源策略

| 项 | 说明 |
| --- | --- |
| 设计 | 异常设计 |
| 作者 | 孙文龙 |
| 模式 | Open Core |
| 公开许可 | Apache License 2.0 |
| 不公开（暂） | 技能中控台源码、试用绑定、发版注入；将随项目推进逐步开源 |
| 架构 | 模块化单体（不是微内核） |

## 分工

- **私有完整树**（本机 / Codeup）：权威源码与打包。
- **公开仓**（GitHub）：功能版核心子集；由维护者导出后合并，不自动镜像。

公开 Release 当前提供全功能试用二进制，便于尽早解决问题；作者承诺持续提供免费可用版本，并在稳定后发布不限时全功能包。未进公开仓的模块以打磨与 review 为主，计划逐步开源，而非永久闭源。

## 公开范围

公开：本地网关与协议适配、模型管理、Claude / Codex / OpenCode 等通用接管、功能版 UI 与 CLI、构建说明与截图。

不公开：`src/store/`、`src-tauri/src/store/`、`SkillsPanel`、试用机绑实现细节、打包脚本与通知配置、内部 PRD。

清单见私有树 `docs/public-manifest.md`。构建说明见 [build.md](./build.md)。

## 许可

公开核心采用 Apache-2.0，便于审阅与二次集成，并保留专利相关条款。闭源模块由异常设计保留权利；试用包条款以 Release 说明为准。
