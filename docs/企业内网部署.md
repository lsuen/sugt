# 企业内网部署（key 不出公司）

> 适用场景：小团队 / 小企业内部署一台 SUGT 网关，真实 LLM Key 只在服务端，**员工机器永不见真实 Key**，只持有一个内部「项目 Key」。

## 原理

```
员工机器 (Claude Code / Codex)
   │  ANTHROPIC_BASE_URL / OPENAI_BASE_URL 指向内网网关
   │  ANTHROPIC_AUTH_TOKEN / OPENAI_API_KEY = 内部项目 Key
   ▼
内网 SUGT 网关 (sugt-cli serve --lan)
   │  校验内部项目 Key，转发到上游
   ▼
上游 LLM (真实 Key 只在服务端配置里)
```

- 员工端只配置「内网网关地址 + 内部项目 Key」，真实上游 Key 不落地到任何员工机器。
- 内网模式下网关**强制校验**内部项目 Key（`gateway_auth`）；非回环绑定且 Key 为空/默认时，`sugt-cli` 会**自动生成强密钥并落盘**，不会以默认 Key 裸奔。

## 一键部署（服务端）

在准备当网关的内网机器（Linux / Windows 均可，建议 Linux 常驻）执行：

```bash
# 1. 初始化并生成强密钥 + 开启局域网 + 打印员工接入片段
sugt-cli team setup

# 2. 启动网关（内网模式）
sugt-cli serve --lan
```

`team setup` 会输出一段可直接分发给员工的命令，形如：

```bash
# 内网地址 http://192.168.1.10:8787 — Claude Code
export ANTHROPIC_BASE_URL=http://192.168.1.10:8787
export ANTHROPIC_AUTH_TOKEN=<KEY>

# 内网地址 http://192.168.1.10:8787 — Codex / OpenAI 兼容
export OPENAI_BASE_URL=http://192.168.1.10:8787/v1
export OPENAI_API_KEY=<KEY>
```

把 `<KEY>` 替换为 `team setup` 打印出的 `gateway_client_api_key`，发给每位员工即可。

## Linux 常驻（systemd）

```bash
# 打印服务单元模板，保存到 /etc/systemd/system/sugt-gateway.service
sugt-cli team service

sudo systemctl daemon-reload
sudo systemctl enable --now sugt-gateway
```

Windows 更简单：把 `sugt-cli serve --lan` 放进「任务计划程序」开机启动即可。

## 浏览器管理台（可选）

服务端启动网关时加 `--webui`，管理员即可从内网任意设备用浏览器管理，不必 SSH 到服务器上敲命令：

```bash
sugt-cli serve --lan --webui                 # WebUI 默认 8788 端口
sugt-cli serve --lan --webui --webui-port 9000
```

浏览器打开 `http://<网关内网IP>:8788`，用 `gateway_client_api_key` 登录。可管理 Provider、技能、接入 Key、日志、策略规则等，和桌面 GUI 同一套管理面。

- `--webui` / `--webui-port` 只影响本次运行，不写配置；systemd 单元模板里加这两个参数即可长期生效。
- 持久化配置请用 `sugt-cli webui on --port 8788`（GUI 启动会自动读取）。
- WebUI 与网关各自独立监听端口，需放通防火墙的 8787（网关）与 8788（WebUI）。
- 登录令牌由 `gateway_client_api_key` 签发，改 Key 后所有会话立即失效；详见 [局域网 WebUI 管理](局域网WebUI管理.md)。

## 安全注意

- 内部项目 Key 等同「能花你们公司 LLM 额度」的凭证，按员工/部门分发，离职即轮换（改 `gateway_client_api_key` 后重启网关）。
- 当前为 HTTP（信任内网）。若跨不信任网段，请在网关前挂反向代理 + TLS，再让员工指向 `https://`。
- 网关本身仍需配置一个可用的上游 Provider（`sugt-cli init --base-url ... --api_key ... --model ...` 或 GUI 添加），否则员工请求无上游可转发。
