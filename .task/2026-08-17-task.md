# 2026-08-17 需求拆分：Anthropic 原生优先 + 转换规则强化 + 控制台 Agent 接入点 UI 优化

## 需求背景

1. **原生优先机制**：识别到 Claude 系客户端（TUI/GUI）时，优先尝试 LLM 服务商的原生 Anthropic 端点（利用 provider_catalog 中已有的 `anthropic_base_url`），尝试失败（不支持）后再走 OpenAI→Anthropic 转换规则（转换作为 fallback）。
2. **转换规则强化**：修复当前"有时还会报错"的问题（错误体透传、tool_choice auto 对象、null 字段）。
3. **转换增强**：数组 content、图片 base64、reasoning 映射。
4. **控制台 Agent 接入点 UI 优化**：上游/下游归拢、协议切换按钮（openai/anthropic/auto）、文案精简、复制按钮。

## 阶段一：原生优先 + fallback 缓存

### 1.1 客户端特征识别
- 位置：`src-tauri/src/` 新增 `anthropic_client_detect.rs`
- 功能：`detect_anthropic_client(headers) -> Option<AnthropicClientKind>`
- 匹配规则（User-Agent，大小写不敏感 + 特征词）：
  - `claude-cli` / `claude-code` → ClaudeCode（TUI）
  - `claude-desktop` → ClaudeDesktop（GUI）
  - `cline` / `roo-cline` / `continue` / `windsurf` / 含 `claude` / 含 `anthropic` → OtherAnthropic

### 1.2 原生端点解析
- 位置：`gateway.rs` 或新模块
- 功能：`anthropic_native_target(provider) -> Option<String>`
- 逻辑：
  - protocol == Anthropic → 直接用 base_url（维持现状）
  - protocol == OpenAI → 查 catalog 的 `anthropic_base_url`；未命中则不瞎猜返回 None

### 1.3 分流改造
- 位置：`gateway.rs::proxy_anthropic_request`
- 逻辑：
  - 识别到 Claude 客户端：
    - 先尝试原生端点（`proxy_anthropic_native`）
    - 原生失败（404/405/响应体明确不支持）→ fallback 转换（`proxy_anthropic_via_openai`）
    - 其它 4xx（鉴权失败等）如实返回
  - 未识别到 Claude 客户端：维持现状（OpenAI 协议直接转换，Anthropic 协议直接原生）
- 新增 per-provider "原生不支持" 缓存：`RwLock<HashSet<String>>`，避免每次请求都白打一次失败的 HTTP 请求

### 1.4 缓存失效
- provider 配置变更（save_provider / delete_provider）时清理缓存

## 阶段二：转换高优 bug 修复

### 2.1 错误体透传（最高优先级）
- `openai_to_anthropic_response`：非 2xx 时把 OpenAI 格式错误体转换为 Anthropic 格式：
  `{"type":"error","error":{"type":"api_error","message":"..."}}`

### 2.2 tool_choice 对象形式
- `anthropic_tool_choice_to_openai`：
  - `{"type":"auto"}` → `"auto"`
  - `{"type":"none"}` → `"none"`
  - `{"type":"any"}` → `"required"`
  - `{"type":"tool","name":...}` → 已有

### 2.3 null 字段过滤
- 转换时跳过 `temperature`/`top_p`/`stop_sequences` 等为 null 的字段

## 阶段三：转换增强

### 3.1 流式 delta.content 数组
- `delta.content` 为数组时提取 text 部分

### 3.2 图片块转换
- Anthropic `image` 块 → OpenAI base64 `image_url` content 块

### 3.3 reasoning 映射
- 非流式：`message.reasoning_content` → Anthropic `thinking` 块
- 流式：`delta.reasoning_content` → `thinking_delta`
