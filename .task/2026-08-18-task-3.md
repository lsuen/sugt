## 方案要点

### 1. 恢复默认

- 保留 `enabled`/`show_tokens`/`show_client`（不误关），仅重置：
  - `opacity 0.7`、`x/y -1`（重新右上角定位）、`layout column`、`width 260`、`height 76`
  - `edit: false` 退出移动模式
- 位置重置为 -1 后，后端 `apply` 的未定位分支会自动回主屏右上角

### 2. 横排/竖排切换

- 前端按钮切换 `layout`，同时应用推荐尺寸（column 260×76 / row 420×48）
- `overlay.tsx` 渲染：`isRow ? 'overlay-rows-h' : 'overlay-rows'`
  - 竖排：两行上下；横排：两行并排（`.overlay-rows-h .overlay-row { flex: 1 1 0; min-width: 0 }`）
- 保存按钮 + 抓手始终在第一行（横排时即右上角）

### 3. 尺寸调整

- 滑块（宽 200~600 / 高 48~160）拖拽中本地 state，松开/键盘提交 `set_overlay_config`
- 后端 `apply` 每次更新调 `set_size(LogicalSize::new(cfg.width, cfg.height))`

### 4. 参数校验（后端兜底）

- `layout` 必须是 `column` 或 `row`
- `width ∈ [120, 800]`、`height ∈ [40, 300]`
