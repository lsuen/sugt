# 2026-08-18 需求拆分：流量悬浮窗（置顶 + 半透明 + 鼠标穿透）

## 需求背景

用户要求：流量悬浮窗——置顶 + 鼠标穿透 + 半透明的小窗，实时显示 token 交互；设置页提供开关与属性。编码规范：最精简代码（少 clone、Option/Result 链式、迭代器优先、少字段、不引多余 crates、短变量名、~100 字符行宽）。

## 方案要点

- **后端**（已实现，未提交）：`OverlayConfig`（enabled/opacity/edit/show_tokens/show_client/x/y）、`overlay.rs`（创建/更新/销毁窗口，edit 时临时关闭穿透）、`set_overlay_config` 命令、启动恢复、tauri feature `windows-ignore-cursor-events`。
- **数据复用**：`GatewayStatsCollector` 已累计 today_input_tokens / today_output_tokens，overlay 页面轮询 `get_status`（3s）即可，不新增统计。
- **编辑定位**：设置页「移动悬浮窗」→ edit=true（穿透关闭可拖动）；overlay 页面显示「保存位置」按钮，点按用 `outerPosition` 取位置 → `set_overlay_config` 保存并退出编辑。
- **事件同步**：`set_overlay_config` 成功后后端 emit `sugt://overlay-config-changed`，overlay 页面据此更新 edit/显示项，免轮询 get_config。

## 阶段一：vite 多入口 + overlay 页面

### 1.1 vite.config.ts
- `rollupOptions.input` 增加 `overlay: resolve(__dirname, 'overlay.html')`
- overlay 页面独立构建，main 入口不受影响

### 1.2 overlay.html
- 独立 html（透明背景），引 `/src/overlay.tsx`

### 1.3 src/overlay.tsx
- 启动：`get_config()` 拿 overlay 配置（edit/show_tokens/show_client）
- 定时 3s：`get_status()` 更新 token / 最近来源
- 显示行（按 show_tokens / show_client 裁剪）：输入 token、输出 token、最近客户端、最近模式
- edit=true：显示「保存位置」按钮 → `getCurrentWindow().outerPosition()` → `set_overlay_config`
- 监听 `sugt://overlay-config-changed` 同步 edit / 显示开关

## 阶段二：设置页开关 + 属性

### 2.1 SettingsPanel.tsx
- 新分组「流量悬浮窗」：
  - 开关：启用悬浮窗（enabled）
  - 透明度：range 滑块（0.1~1.0），松手提交
  - 开关：显示 Token / 显示来源
  - 按钮：移动悬浮窗（edit=true）
- 需要 `config.overlay` 字段

### 2.2 main.tsx
