## 方案要点

### 1. 保存按钮挪到第一行

- 第一行「流量 + [保存]」紧凑：标签 + tokens + 按钮（行 1 ≈ 110px 内）
- 第二行「来源」占满，文字 ellipsis 不再挤压按钮
- 「保存」两字比「保存位置」四字省 24px，避免 260px 窗口右侧截断

### 2. 拖动修复（drag region 命中子元素）

- `data-tauri-drag-region` 标记到 **overlay-row**（每个可拖动行）
- 「保存」按钮加 `data-tauri-no-drag`：可点击，不会因为按下时处于 drag region 而无法响应 onClick
- Tauri 2 webview 命中测试按元素，配这两个属性后整块可拖、按钮可点

### 3. 默认右上角

- `OverlayConfig.x/y` 用 `-1` 作为「未定位」标记（serde default 函数返回 -1）
- `overlay::apply` 创建窗口分支：调用 `top_right(app)` 计算 `primary_monitor().size() / scale - WIDTH - 16`，将结果写回 `cfg.x/y` + runtime config
- 用户「保存位置」后 cfg.x/y 写入真实值
- 设置面板展示：若 `cfg.x < 0` 显示「未定位（自动右上）」，否则显示 `(x, y)`

### 4. 副屏丢失回主屏

- `overlay::apply` 的 update 分支调用 `ensure_on_screen`：
  - 遍历 `available_monitors()`，检查 cfg.x/y 是否在任一 monitor 范围内
  - 不在 → `top_right` 重置 + 写回 cfg（runtime）
- 代码预算 ≤ 50 行（top_right + ensure_on_screen + write_back）

### 5. 设置页布局

- 当前 8 个 card 中 5 个 `settings-group-wide` 全宽 + 3 个窄 → 视觉零散
- 改：分 **2 子 tab**（基础 / 高级），子 tab 内 grid 2 列（已存在），所有 card 不再用 wide
  - 基础：启动 + 网关 + 网络与退出 + 流量悬浮窗 + 本地接入点
  - 高级：实验功能 + 技能商店 + 客户端接管
- 子 tab 用 useState 控制，按钮复用现有 `.ghost .tiny-btn` 风格（与日志工具栏类似 `.active` 高亮）
